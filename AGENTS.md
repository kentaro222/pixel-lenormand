# Project workflow

- Increment the displayed version for each delivered app update (v0.4 → v0.5 → v0.6, etc.). Keep the document title, visible heading, and eyebrow version in index.html consistent.
- Verify changes without showing layout screenshots to the user; the user checks the app directly.
- After verification, commit the requested app changes and push to origin main. Do not force-push; preserve remote changes. Report any push failure accurately.
