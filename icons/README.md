# PIXEL LENORMAND icons

Standalone icon artwork inspired by the star card (No. 16) in
`../lenormand_sprites.png`, using forest green, antique gold and cream.
The source was generated with the existing sprite sheet as a reference.

- `icon-source.png`: full-resolution source (1254 × 1254)
- `icon-512.png`, `icon-192.png`: application icons
- `icon-180.png`: Apple touch icon size
- `icon-16.png`, `icon-32.png`, `icon-48.png`: small PNG icons
- `favicon.ico`: 16, 32 and 48 pixel images in one ICO file

Sizes were exported with nearest-neighbor resampling to retain pixel edges.
These files are intentionally not linked or embedded in HTML. The ICO also
stays in this directory to avoid automatic root `/favicon.ico` discovery.
